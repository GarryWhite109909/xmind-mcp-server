# 第四章 文件管理

## 一、文件系统基础

### 1. 文件的基本概念

- 文件：以非挥发性方式存储在介质上的有名称的信息集合
- 文件是OS管理信息的最小单位

### 2. 文件的属性

- 名称、类型、创建者、创建时间、修改时间
- 大小、位置、保护信息（权限）

### 3. 文件控制块FCB

- 文件存在的标志
- 包含：
  - 基本信息：文件名、物理位置
  - 存取控制信息：权限
  - 使用信息：创建时间、修改时间

### 4. 索引节点inode

- FCB的改进版
- 把文件名和文件描述信息分开
- 文件目录只存文件名+inode号
- 描述信息存inode中
- 优点：目录项变小，查找更快

### 5. 文件的操作

#### 基本操作

- 创建文件 create
- 删除文件 delete
- 打开文件 open：把FCB读入内存打开文件表
- 关闭文件 close
- 读文件 read
- 写文件 write
- 截断文件 truncate

#### 打开文件表

- 系统级打开文件表：整个系统一张
- 进程级打开文件表：每个进程一张
- 打开文件后用文件描述符fd访问

### 6. 文件的逻辑结构

#### 无结构文件（流式文件）

- 字节流，无内部结构
- 例：Unix文件

#### 有结构文件（记录式文件）

##### 顺序文件

- 记录按顺序排列
- 串结构：按关键字顺序
- 顺序结构：按记录顺序
- 优点：批量处理高效
- 缺点：增删困难

##### 索引文件

- 建立索引表
- 主文件可变长记录
- 索引表定长，便于查找
- 优点：查找快
- 缺点：索引表占空间

##### 索引顺序文件

- 主文件按关键字排序
- 每组建立索引项
- 索引项少，查找较快

##### 直接文件/散列文件

- 通过哈希函数定位记录
- 优点：直接访问快
- 缺点：冲突问题

### 7. 文件的物理结构（重点）

#### 连续分配

- 文件占用连续的磁盘块
- FCB中记录起始块号和长度
- 优点：顺序访问快，随机访问快
- 缺点：外部碎片，文件不能动态增长

#### 链接分配

##### 隐式链接

- 每个块含下一块的指针
- FCB记录起始块号和结束块号
- 优点：无外部碎片，可动态增长
- 缺点：随机访问慢，指针占空间，可靠性差

##### 显式链接

- 把所有链接指针集中到FAT表
- FAT常驻内存
- 优点：随机访问快
- 缺点：FAT占内存
- 代表：FAT文件系统

#### 索引分配

- 每个文件建立索引表
- FCB中含索引表地址
- 优点：随机访问快，无外部碎片
- 缺点：索引表占空间

##### 索引表的处理

- 单级索引：索引表存放在一个块
- 多级索引：索引表指向下级索引
- 混合索引：直接地址+一级索引+二级索引+三级索引（Unix inode）
  - 小文件：直接地址
  - 中文件：一级索引
  - 大文件：多级索引

##### 混合索引计算（大题高频）

**典型结构（Unix inode）**：
- 直接地址项：12个（直接指向数据块）
- 一级间接地址项：1个
- 二级间接地址项：1个
- 三级间接地址项：1个

**计算最大文件大小**：
- 设盘块大小 = S 字节，盘块号占 = P 字节
- 一个索引块可存放的指针数 = S / P
- 最大文件 = 12 × S + (S/P) × S + (S/P)² × S + (S/P)³ × S

**计算给定文件大小需要的盘块数**：
- 先判断文件属于哪个范围（直接/一级/二级/三级）
- 再计算需要多少索引块和数据块
- 注意：大文件需要多级索引块，索引块本身也占用盘块

> 考研重点：混合索引计算是**文件管理大题高频考点**，不仅要算最大文件大小，还要算给定文件长度需要多少盘块/索引块。注意单位换算：1KB = 1024B，盘块大小和盘块号占用的字节数要分清

#### 三种物理结构对比

| 结构 | 顺序访问 | 随机访问 | 碎片 | 增长 |
|------|---------|---------|------|------|
| 连续 | 快 | 快 | 外部 | 难 |
| 链接 | 快 | 慢 | 无 | 易 |
| 索引 | 中 | 快 | 无 | 易 |

### 8. 文件保护

#### 访问类型

- 读R、写W、执行X、附加A

#### 访问控制方式

##### 访问控制表ACL

- 每个文件一张表，记录每个用户的权限
- 精细，但开销大

##### 访问权限表

- 每个用户一张表，记录能访问哪些文件

##### 口令

- 文件设密码
- 简单但易泄露

##### 密码

- 加密文件内容
- 安全但开销大

#### UNIX的文件权限

- 三类用户：所有者、同组、其他
- 三种权限：rwx
- 用9位表示

## 二、目录

### 1. 目录的基本概念

- 目录：文件控制块的有序集合
- 目录本身也是文件

### 2. 目录的操作

- 创建、删除、读目录、改目录、检索

### 3. 目录结构

#### 单级目录

- 整个系统一张目录表
- 优点：简单
- 缺点：不能重名、查找慢

#### 两级目录

- 主文件目录MFD + 用户文件目录UFD
- 优点：允许重名
- 缺点：用户间不便共享

#### 树形目录（重点）

- 多级层次结构
- 路径：
  - 绝对路径：从根开始
  - 相对路径：从当前目录开始
- 优点：层次清晰、便于管理
- 现代OS主流

#### 无环图目录

- 树形目录+共享子目录
- 支持文件共享
- 用链接实现共享

### 4. 目录实现

##### 线性表

- 简单，但查找慢

##### 哈希表

- 查找快，但有冲突

### 7. 文件共享

#### 硬链接

- 多个目录项指向同一inode
- 共享同一文件
- 删除一个链接不影响其他
- 计数器管理（inode引用计数）
- **硬链接不能链接目录**（防止环路死循环）
- 不能跨文件系统（inode号在不同文件系统无意义）

#### 软链接（符号链接）

- 一个文件指向另一个文件的路径
- 类似快捷方式
- 删除原文件则软链接失效
- 可跨文件系统
- **软链接的I/O开销**：如果路径名很长，访问原文件需逐级解析路径，增加磁盘I/O次数

## 三、文件系统

### 1. 文件系统结构

- 文件系统：OS中管理文件的软件
- 层次：
  - 应用 → 系统调用 → 文件系统 → 设备驱动 → 磁盘

### 2. 文件系统布局

#### 磁盘布局

- 引导区MBR
- 文件系统控制块（**超级块**）：包含文件系统的魔数（Magic Number）、总块数、空闲块数、inode数量、块大小等元数据
- 位示图区（盘块分配状态）
- inode区
- 数据区

#### 内存布局

- 系统打开文件表
- 进程打开文件表
- 目录缓存

### 3. 文件存储空间管理

#### 空闲表法

- 记录空闲区的起始和长度
- 适合连续分配

#### 空闲链表法

- 空闲盘块链：每个块含下一块指针
- 空闲盘区链：连续空闲区一组

#### 位示图法（重点）

- 每个盘块一位：0空闲，1占用
- 优点：占空间小，操作快
- 计算：
  - 字长n位，第i位对应块号
  - 块号b对应的字 = b / n，位 = b % n
  - 字w第j位对应的块号 = w × n + j

#### 成组链接法

- Unix使用
- 把空闲块分组，组间用链接
- 适合大容量磁盘

### 4. 虚拟文件系统VFS

#### 作用

- 统一不同文件系统的接口
- 用户用统一系统调用访问不同文件系统

#### VFS的四大对象

- superblock：超级块对象，文件系统信息
- inode：索引节点对象
- dentry：目录项对象
- file：文件对象

### 5. 文件系统挂载

- mount：把文件系统挂到目录树
- 一个目录可挂载不同文件系统

- FCB和inode的区别
- 文件的物理结构对比（连续/链接/索引）
- 混合索引计算（Unix inode）
- 目录结构的演变
- 软硬链接的区别
- 位示图计算
- VFS的四大对象

### 2. 高频计算

- 混合索引文件大小计算

### 3. 易混概念

- 逻辑结构 vs 物理结构

- 隐式链接 vs 显式链接
- 单级索引 vs 多级索引

## 五、易错点

### 1. FCB vs inode陷阱

- FCB含文件名
- inode不含文件名（文件名在目录项中）
- 引入inode后目录项更小

### 2. 物理结构陷阱

- 连续分配有"外部碎片"（注意不是内部）
- 链接分配无碎片
- 索引分配的索引表占空间
- 显式链接的FAT常驻内存

### 3. 混合索引陷阱

- 直接地址项能寻址的块数 = 直接项数
- 一级索引能寻址的块数 = (块大小/指针大小)
- 二级索引能寻址的块数 = (块大小/指针大小)^2
- 文件最大 = 直接 + 一级 + 二级 + 三级
- 注意单位换算

### 4. 位示图陷阱

- 块号从0还是1开始
- 位号从0还是1开始
- 注意"字长"和"位号"的换算
- (块号b, 字长n) → 字号b/n，位号b%n

### 5. 软硬链接陷阱

- 硬链接：共享同一inode，引用计数+1
- 软链接：自己的inode，存原文件路径
- 删除原文件：硬链接仍可访问（计数减1），软链接失效
- 软链接可跨文件系统，硬链接不能

### 6. 文件打开陷阱

- 打开文件是把FCB/inode读入内存
- 文件描述符fd是进程级打开文件表的索引
- 多次打开同一文件会有多个fd，但共用一个系统级表项

### 7. 目录结构陷阱

- 树形目录：绝对路径从根开始
- 路径中"."是当前目录，".."是上级
- 无环图目录：支持共享，需处理循环
